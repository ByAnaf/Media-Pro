## 🌌 Overview
Media Pro is a high-performance web tool designed to extract and download media files seamlessly. Featuring a custom **glassmorphism** interface and a robust API-first architecture, it ensures that your downloads are handled with a premium, clutter-free experience.

## ✨ Features
*   **Universal Support:** Optimized for various social media platforms.
*   **Direct Pipeline:** Downloads content directly to your device without intrusive redirects.
*   **Zinc-Themed UI:** A minimalist, high-contrast dark aesthetic for a premium feel.
*   **Intelligent Fallbacks:** Automated engine switching to ensure maximum uptime.

## 🛠 Tech Stack
*   **Frontend:** HTML5, CSS3 (Glassmorphism), Vanilla JavaScript.
*   **API Engine:** Cobalt API (High-Quality JSON).
*   **Host:** GitHub Pages.

## 🚀 Usage
1. Paste your video or reel link into the input field.
2. Click **GENERATE DOWNLOAD**.
3. Your file will be processed and downloaded directly.
